Project Overview
 
This project focuses on implementing a binary image classification model using deep learning techniques. The aim is to train a neural network to distinguish between two classes of images taken through camera traps with high accuracy. The task was completed as part of the AI Lab – Computer Vision for Deep Learning course at WorldQuant University.

Acknowledgment

This project was developed as part of the Artificial Intelligence Nanodegree (AI Lab) offered by WorldQuant University. I am deeply grateful to the institution, its faculty, and the broader AI Lab community for their invaluable support and mentorship throughout the learning journey.

Key Features

•	Preprocessing pipeline with image resizing and normalization
•	Use of PyTorch for model development and training
•	Binary classification using CNN architecture
•	Visualization of training and validation accuracy/loss
•	Evaluation metrics: accuracy, precision, recall
Technologies Used

•	Python
•	PyTorch
•	torchvision
•	NumPy, Matplotlib
•	Jupyter Notebook
